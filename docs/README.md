## Documentation conventions

- Commands run from the repository root unless stated otherwise.
- Replace values in angle brackets before running commands.
- Never include real access tokens, cookies, passwords, or encryption keys in documentation, screenshots, issues, or logs.
- If implementation and documentation disagree, treat current code and tests as the source of truth and open a documentation bug.
