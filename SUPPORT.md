# Support

## Questions and troubleshooting

Start with the [documentation index](docs/README.md), especially the [configuration](docs/reference/configuration.md) and [operations](docs/operations/README.md) guides.

For reproducible defects, open a [bug report](https://github.com/andjoy404/anjoy-gitops/issues/new/choose). Include the application version, browser, deployment method, steps to reproduce, and sanitized logs.

For ideas and product improvements, open a feature request.

## Security issues

Do not use public support channels for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Scope

Community support is best effort. Please avoid posting GitLab tokens, passwords, encryption keys, private repository names, or other sensitive infrastructure details.
